Calculator App

A modern approach to basic math.

This project was built to challenge my understanding of JavaScript logic and DOM manipulation. I wanted to create a calculator that wasn't just functional, but also visually pleasing and responsive on mobile devices.


The Process: I started by designing the layout using CSS Grid to ensure the buttons were perfectly aligned. Then, I used JavaScript to capture user input, handle mathematical operations, and display the results dynamically without reloading the page.


What I Learned: This project solidified my knowledge of event listeners, string manipulation, and how to structure clean, readable functions in JavaScript.
